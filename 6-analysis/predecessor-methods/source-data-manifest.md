## Methodological cautions discovered from primary sources

### GCM
O'Micks explicitly states there is no single universal JCV cutoff for assigning baramins and that interpretation depends on organismal biology. PDP therefore pre-registers that it will not invent a Canidae threshold post hoc.

GCM's PGQ/CI interpretation as genome erosion from an archebaramin is an original-model interpretation. PDP may reproduce the quantities without adopting that historical interpretation.

### WGKS
The 2020 source compares WGKS against mitochondrial and GCM clustering. PDP will reproduce the numerical similarity/clustering behavior first. Any claim that WGKS is "more accurate" as a kind detector remains an interpretation requiring an independent criterion.

### Lightner 2009
The paper's key quantitative boundary observation is directly relevant: one diploid Ark pair can carry no more than four allelic versions at an autosomal locus. Its proposed designed-change interpretation is a predecessor hypothesis and is not built into the reproduction.

## Freeze rule

The exact assembly/proteome accession table is frozen before running GCM or WGKS. A taxon may be excluded only by a predeclared quality/completeness criterion, not because its inclusion changes the preferred cluster.

## Source hierarchy

1. Original paper/method publication.
2. Primary public sequence/database record.
3. Later primary application/reproduction.
4. Secondary discussion only when the primary source is inaccessible, labeled as such.
