# Darwin's Finches

**Status:** Recorded observation. Usable as a rate example (charter Rule 1).

## What is recorded

- Beak size and shape shifts within decades under selection.
- One hybrid lineage reproductively isolated from local birds in a few
  generations.

## What it establishes

- That selection can move morphology within decades given variable stock:
  a rate bound for the selection auxiliary
  (`2-theory/diversification/selection.md`).
- That reproductive isolation can arise in a few generations: a rate bound
  for the speciation auxiliary
  (`2-theory/diversification/speciation.md`).

## What it does not establish

That the post-Flood history occurred (charter Rule 1).
