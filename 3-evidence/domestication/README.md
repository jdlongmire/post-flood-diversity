# Domestication (evidence stream)

Reserved evidence stream extending the recorded cases in
`observed-diversification/`.

Holds historical and archaeological findings on domestication-driven
diversification: timelines, magnitudes, and mechanisms of breed formation
under human management.

Note the limit: domestication involves directed selection by breeders.
Using it as a rate bound for unmanaged post-Flood diversification requires
an explicit auxiliary registering the difference; do not smuggle managed
rates in as natural ones.
