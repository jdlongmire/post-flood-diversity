# Severe Tests

**Status:** Reserved; success criteria pre-registered here as tests are
designed.

Candidate severe tests (hardest first):

1. **Chiroptera (PDP-TAX-007).** Deriving bats from a mammalian founder
   population under the body-plan kind hypothesis. If a body-plan-level
   mammalian kind is proposed, this is the test that decides whether the
   hypothesis survives.
2. **Founder genome feasibility (PDP-03).** A quantified demonstration that
   a founder pair's four-copy-limited genome can encode a whole plan's
   descendant diversity, or a clean failure with the shortfall named.
3. **Whole-plan worked kind (PDP-06).** The kind-by-kind account the seed
   specification identifies as missing: this pair, these alleles and
   pathways, this much selection, these descendants by the catalogues.

A test is severe only if the programme can fail it. Pre-register the
criteria; do not move them after the fact.
