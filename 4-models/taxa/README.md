# Taxa (models)

Worked kind-by-kind demonstrations: the PDP-06 work product.

Each taxon directory carries one taxon end to end:

```
Founder stock
      |
Founder genomic state
      |
Standing variation + post-Flood mutation
      |
recombination + selection
      |
isolation / dispersal
      |
population differentiation
      |
reproductive isolation where applicable
      |
observed descendant diversity
```

## Order (progressively harder)

- PDP-TAX-001 Canidae (calibration)
- PDP-TAX-002 Bovidae
- PDP-TAX-003 Equidae
- PDP-TAX-004 Ursidae
- PDP-TAX-005 Felidae
- PDP-TAX-006 Muridae
- PDP-TAX-007 Chiroptera (severe test)
- PDP-TAX-008 Aves test cluster

Each worked taxon must state its founder assumptions, its belt auxiliaries
invoked (with registry IDs), and its success criteria in advance. A worked
kind that changes the founder population, chronology, or hard-core event to
succeed is a programme revision (charter Rule 2), not a success.
