# Kind Registry (models)

Machine-readable records for candidate kinds, mirroring `registry/KINDS.md`.

Each kind record states: the hypothesis it belongs to (body-plan cut vs
family-level cut), the evidence cited (morphology, reproductive
compatibility, comparative genomics, developmental architecture,
phylogenetic structure), its status (competing, provisional, resolved),
and the founder-stock assumption it entails.

Reserved for PDP-02. Records are model inputs, not evidence: keep the
registry's claims traceable to `registry/KINDS.md` and
`traceability/claims.yaml`.
