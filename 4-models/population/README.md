# Population (models)

Population-genetic models of the founder stocks: what a founder pair can
encode and transmit under the four-copy autosomal constraint
(`2-theory/genetics/allele-constraints.md`).

Reserved for PDP-03 (Founder Genome Feasibility), probably the critical
technical stream. Models here must respect the standing constraint; any
model that enriches the founder stock beyond it is a programme revision
(charter Rule 2), not a result.
