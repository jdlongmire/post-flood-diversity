# Diversification (models)

Quantified diversification models: recombination, selection, regulatory
change, isolation, chromosomal rearrangement, mutation, and speciation
operating against the stipulated time window
(`1-boundary/chronology.md`).

Reserved for PDP-04. Rate bounds come from
`2-theory/diversification/rate-models.md`; applying them to Ark founder
populations happens here, as explicit model claims.
